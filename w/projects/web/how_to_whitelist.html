Ubuntu (linux):
   sudo apt-get install dnsmasq

   sudo nano /etc/dnsmasq.conf
     to whitlist a.com enter:
         server=/a.com/8.8.8.8
         address=/#/127.0.0.1

   sudo systemctl restart dnsmasq

   Ask AI for help if needed.

   dnsmasq.conf example


Android:
   Create free account on nextdns.io and login.

   In Setup tab, scroll to:
     Setup Guide
     and follow instructions to change phone:
       Setting - Network - Advanced - Private DNS...


   In Security tab, scroll to:
     Block Top-Level Domains (TLDs)
     and click ADD A TLD
       Click ADD button next .com
       This blocks all .com websites,
       to block all need to select all other domains.

   In Allowlist tab, type whitelist URLs,
   for example:
      abc.com
