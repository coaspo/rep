set
  Collection/group of items.
  Well-Defined/clear/unambiguous ; "set of even numbers" not "set of all beautiful flowers"
  Distinct/unique Objects: {1,2,2,3} is the same as {1,2,3}; objects not repeated.
  Order Doesn't Matter:  {a,b,c} is same as {c,a,b}.
∅ or {} empty Set
|A|=2 Cardinality of (number of elements) A is 2
C ⊆ X Cis subset of X; every element in set C is also an element in set X
1 ∈ A means "1 is an element of set A."

set types
  Empty Set      no elements, cardinality is zero. ∅ or {}
  Subset         C⊆X
  Proper Subset  meaning X has at least one element not in C). C⊂X or C⊊X
  Universal set  all possible elements relevant to problem. U
  Equal Sets     exactly the same elements A=B.
  Equivalent set same number of elements, but elements may be different.  A={1,2} B={x,y}, A=B
  Disjoint Sets  have no elements in common, intersection is empty set.   A={1,2} B={3,4},  A∩B=∅.
  Power Set      all possible subsets of a given set.   A={a,b}, P(A)={∅,{a},{b},{a,b}}.
