Install this extension to Brave (or Chrome?):
    open:
       brave://extensions/
    turn on:
       "Developer Mode"
    click:
       "Load unpacked"
    select folder:
       "prompt chrome extension"


Install to Firefox:
    open:
       about:debugging
    on left select:
       "This Firefox"
    click:
       "Load Temporary Add-on..."
    select folder:
       "prompt chrome extension"
    select:
       "manifest.json"


To run, click:
    Alt - 1
